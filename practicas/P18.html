1 Objetivos de la sesión

Al finalizar esta sesión podrán:

  • Formular (H_0) y (H_1) para una prueba de independencia (cuali–cuali).
  • Construir tablas de contingencia con {janitor} usando pipes y obtener porcentajes por renglón/columna.
  • Aplicar chisq.test() y fisher.test() sobre tabyls (vía {janitor}) e inspeccionar conteos esperados y residuales estandarizados.

  • Reportar ANOVA en formato tidy con {broom} (tidy() y glance()).

df_cc <- concentrado |>

6 3) Chi-cuadrado usando {janitor} (pipes)

{janitor} redefine chisq.test() para que acepte un tabyl y, si lo pides, te regrese también observados/esperados/residuales en formato tabyl.

6.1 3.1 Chi-cuadrado sobre tabyl

res_chi <- tab_cc |>
  chisq.test(tabyl_results = TRUE)

res_chi$statistic
res_chi$parameter
res_chi$p.value

6.2 3.2 Conteos esperados y residuales (para interpretación)

res_chi$expected   # tabyl con conteos esperados
res_chi$stdres     # residuales estandarizados (idea de dónde “está” la asociación)
NotaRegla práctica (esperados)

Si hay muchos conteos esperados < 5, la aproximación chi-cuadrado puede ser dudosa. Para tablas 2×2, considera Fisher.

6.3 3.3 Fisher (alternativa) sobre tabyl

res_fisher <- tab_cc |>
  fisher.test()

res_fisher$p.value

8 5) Puente hacia ANOVA (3+ grupos) + salida tidy con {broom}

Ejemplo: comparar media de ing_cor entre categorías de tam_loc (4 grupos).

df_anova <- concentrado |>
  filter(!is.na(ing_cor), !is.na(tam_loc)) |>
  mutate(tam_loc = factor(tam_loc))

8.1 5.1 ANOVA base

m1 <- aov(ing_cor ~ tam_loc, data = df_anova)
summary(m1)

8.2 5.2 ANOVA tidy con broom (estilo “publicable”)

anova_tidy <- broom::tidy(m1)
anova_glance <- broom::glance(m1)

anova_tidy
anova_glance

8.3 5.3 Post-hoc: Tukey HSD (comparaciones múltiples)

Si el ANOVA sugiere diferencias globales entre grupos, un paso típico es un post-hoc para identificar qué pares de grupos difieren, controlando el error por comparaciones múltiples.

tuk <- TukeyHSD(m1)
tuk

Versión “tidy” (útil para reporte), si quieres:

tuk_tidy <- broom::tidy(tuk)
tuk_tidy
NotaLectura rápida de Tukey HSD
  • Cada fila es una comparación par a par (por ejemplo, tam_loc 1 vs 2).
  • diff es la diferencia de medias.
  • lwr y upr son el intervalo de confianza ajustado.
  • p adj es el p-valor ajustado por comparaciones múltiples.
ImportanteIntuición del estadístico F

ANOVA compara variación entre medias de grupos vs variación dentro de grupos.
F grande sugiere diferencias entre grupos (pero hoy no hacemos post-hoc).

8.4 5.4 (Opcional) Medias por grupo (para lectura sustantiva)

df_anova |>
  group_by(tam_loc) |>
  summarise(
    n = n(),
    media = mean(ing_cor, na.rm = TRUE),
    mediana = median(ing_cor, na.rm = TRUE),
    .groups = "drop"
  )
