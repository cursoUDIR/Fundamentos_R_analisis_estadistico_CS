Sesión 11: Gráficos univariados para cualitativas

Barras/columnas, proporciones vs conteos, ordenamiento de categorías y coord_flip()

Autores/as

Ana Escoto

Mónica Lara

Fecha de publicación

19 de mayo de 2026

1 Objetivos de la sesión

Al finalizar esta sesión podrán:

  • Construir gráficos univariados para variables cualitativas con ggplot2 (barras/columnas).
  • Diferenciar y aplicar conteos vs proporciones (porcentaje) en gráficos.
  • Ordenar y agrupar categorías para comunicación efectiva (fct_reorder(), fct_lump()).
  • Mejorar legibilidad con coord_flip() y elecciones de escala/etiquetas.
  • Exportar una figura lista para reporte con ggsave().

2 Contenidos

  • Gráficos univariados para cualitativas: geom_bar() y geom_col().
  • Conteos vs proporciones; cuándo conviene cada uno.
  • Ordenamiento y reducción de categorías con {forcats}.
  • Etiquetas y formatos con {scales}.
  • Buenas prácticas: títulos, ejes, notas y exportación.

Paquetes: {ggplot2} {dplyr} {forcats} {scales} {janitor}
Funciones clave: geom_bar() · geom_col() · fct_reorder() · fct_lump() · coord_flip() · scale_y_continuous() · label_percent() · ggsave()

Trabajaremos con una tabla a nivel hogar (ENIGH 2024 como ejemplo).
En los ejemplos asumimos que ya cuentan con un objeto llamado concentrado.

4.1 Lectura sugerida (elige una)

concentrado <- arrow::read_parquet(here::here("data", "raw", "concentradohogar.parquet")) |>

concentrado <- readr::read_csv(here::here("data", "raw", "concentradohogar.csv"),

5 1. Elegir una variable cualitativa

Ejemplos típicos en encuestas de hogares:

  • Tamaño de localidad (tam_loc)
  • Estrato (estrato)
  • Tipo de hogar (si existe)
  • Sexo del jefe/a (si existe)

Ajusta los nombres a tu tabla. Si tu variable está codificada numéricamente, conviene recodificarla a factor con etiquetas antes de graficar.

concentrado |> 
  count(tam_loc) |>
  arrange(desc(n))

6 2. Gráfico de barras (conteos) con geom_bar()

geom_bar() cuenta automáticamente las observaciones (no necesita tabla previa).

ggplot(concentrado, aes(x = as.factor(tam_loc))) +
  geom_bar() +
  labs(
    title = "Distribución de hogares por tamaño de localidad (conteos)",
    x = "Tamaño de localidad",
    y = "Número de hogares (muestra)"
  ) +
  theme_minimal()

7 3. Gráfico de proporciones (porcentaje)

Hay dos formas comunes:

7.1 3.1 Proporciones con estadística en geom_bar(position = "fill")

ggplot(concentrado, aes(x = as.factor(tam_loc))) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(
    title = "Distribución de hogares por tamaño de localidad (porcentaje)",
    x = "Tamaño de localidad",
    y = "Porcentaje"
  ) +
  theme_minimal()

7.2 3.2 Proporciones calculadas previamente (recomendado para control)

tab_prop <- concentrado |>
  count(tam_loc) |>
  mutate(p = n / sum(n))

ggplot(tab_prop, aes(x = as.factor(tam_loc), y = p)) +
  geom_col() +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(
    title = "Distribución por tamaño de localidad (porcentaje)",
    x = "Tamaño de localidad",
    y = "Porcentaje"
  ) +
  theme_minimal()

8 4. Ordenamiento de categorías con {forcats}

Cuando las categorías tienen un orden “analítico” (por ejemplo, mayor a menor frecuencia), conviene ordenar el factor.

tab_prop2 <- concentrado |>
  count(tam_loc) |>
  mutate(tam_loc = forcats::fct_reorder(as.factor(tam_loc), n))

ggplot(tab_prop2, aes(x = tam_loc, y = n)) +
  geom_col() +
  labs(
    title = "Tamaño de localidad ordenado por frecuencia",
    x = "Tamaño de localidad (ordenado)",
    y = "Número de hogares"
  ) +
  theme_minimal()

9 5. Reducir categorías con fct_lump()

Útil cuando hay muchas categorías (ej. estados, municipios, ocupaciones).

Ejemplo genérico (ajusta la variable):

df_lump <- concentrado |>
  mutate(entidad = forcats::fct_lump(as.factor(ubica_geo), n = 10)) |>
  count(entidad) |>
  mutate(entidad = forcats::fct_reorder(entidad, n))

ggplot(df_lump, aes(x = entidad, y = n)) +
  geom_col() +
  coord_flip() +
  labs(
    title = "Top 10 categorías + 'Other' (ejemplo)",
    x = "",
    y = "Número de hogares"
  ) +
  theme_minimal()
NotaNota

En ENIGH, ubica_geo suele ser un código (entidad/municipio). Si quieres un “nombre”, necesitarías un catálogo. En esta práctica el objetivo es el manejo de categorías, no los nombres.

10 6. Mejorar legibilidad con coord_flip()

Cuando hay muchas categorías o etiquetas largas, coord_flip() suele ser la mejor opción.

ggplot(tab_prop2, aes(x = tam_loc, y = n)) +
  geom_col() +
  coord_flip() +
  labs(
    title = "Distribución (conteos) con coord_flip()",
    x = "",
    y = "Número de hogares"
  ) +
  theme_minimal()

11 7. Exportación de una figura

g1 <- ggplot(tab_prop, aes(x = as.factor(tam_loc), y = p)) +
  geom_col() +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(title = "Distribución por tamaño de localidad (porcentaje)",
       x = "Tamaño de localidad", y = "Porcentaje") +
  theme_minimal()

ggsave("fig_p11_categorica.png", plot = g1, width = 7, height = 4, dpi = 300)
