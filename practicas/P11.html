1 Objetivos de la sesión

Al finalizar esta sesión podrán:

  • Construir gráficos univariados para variables cualitativas con ggplot2 (barras/columnas).

5 1. Elegir una variable cualitativa

Ejemplos típicos en encuestas de hogares:

  • Tamaño de localidad (tam_loc)
  • Estrato (estrato)
  • Tipo de hogar (si existe)
  • Sexo del jefe/a (si existe)

Ajusta los nombres a tu tabla. Si tu variable está codificada numéricamente, conviene recodificarla a factor con etiquetas antes de graficar.

concentrado |> 
  count(tam_loc) |>
  arrange(desc(n))

6 2. Gráfico de barras (conteos) con geom_bar()

geom_bar() cuenta automáticamente las observaciones (no necesita tabla previa).

ggplot(concentrado, aes(x = as.factor(tam_loc))) +
  geom_bar() +
  labs(
    title = "Distribución de hogares por tamaño de localidad (conteos)",
    x = "Tamaño de localidad",
    y = "Número de hogares (muestra)"
  ) +
  theme_minimal()

7 3. Gráfico de proporciones (porcentaje)

Hay dos formas comunes:

7.1 3.1 Proporciones con estadística en geom_bar(position = "fill")

ggplot(concentrado, aes(x = as.factor(tam_loc))) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(
    title = "Distribución de hogares por tamaño de localidad (porcentaje)",
    x = "Tamaño de localidad",
    y = "Porcentaje"
  ) +
  theme_minimal()

7.2 3.2 Proporciones calculadas previamente (recomendado para control)

tab_prop <- concentrado |>
  count(tam_loc) |>
  mutate(p = n / sum(n))

ggplot(tab_prop, aes(x = as.factor(tam_loc), y = p)) +
  geom_col() +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(
    title = "Distribución por tamaño de localidad (porcentaje)",
    x = "Tamaño de localidad",
    y = "Porcentaje"
  ) +
  theme_minimal()

8 4. Ordenamiento de categorías con {forcats}

Cuando las categorías tienen un orden “analítico” (por ejemplo, mayor a menor frecuencia), conviene ordenar el factor.

tab_prop2 <- concentrado |>
  count(tam_loc) |>
  mutate(tam_loc = forcats::fct_reorder(as.factor(tam_loc), n))

ggplot(tab_prop2, aes(x = tam_loc, y = n)) +
  geom_col() +
  labs(
    title = "Tamaño de localidad ordenado por frecuencia",
    x = "Tamaño de localidad (ordenado)",
    y = "Número de hogares"
  ) +
  theme_minimal()

9 5. Reducir categorías con fct_lump()

Útil cuando hay muchas categorías (ej. estados, municipios, ocupaciones).

Ejemplo genérico (ajusta la variable):

df_lump <- concentrado |>
  mutate(entidad = forcats::fct_lump(as.factor(ubica_geo), n = 10)) |>
  count(entidad) |>
  mutate(entidad = forcats::fct_reorder(entidad, n))

ggplot(df_lump, aes(x = entidad, y = n)) +
  geom_col() +
  coord_flip() +
  labs(
    title = "Top 10 categorías + 'Other' (ejemplo)",
    x = "",
    y = "Número de hogares"
  ) +
  theme_minimal()
NotaNota

En ENIGH, ubica_geo suele ser un código (entidad/municipio). Si quieres un “nombre”, necesitarías un catálogo. En esta práctica el objetivo es el manejo de categorías, no los nombres.

10 6. Mejorar legibilidad con coord_flip()

Cuando hay muchas categorías o etiquetas largas, coord_flip() suele ser la mejor opción.

ggplot(tab_prop2, aes(x = tam_loc, y = n)) +
  geom_col() +
  coord_flip() +
  labs(
    title = "Distribución (conteos) con coord_flip()",
    x = "",
    y = "Número de hogares"
  ) +
  theme_minimal()

11 7. Exportación de una figura

g1 <- ggplot(tab_prop, aes(x = as.factor(tam_loc), y = p)) +

  labs(title = "Distribución por tamaño de localidad (porcentaje)",
       x = "Tamaño de localidad", y = "Porcentaje") +

ggsave("fig_p11_categorica.png", plot = g1, width = 7, height = 4, dpi = 300)

12 Extra: introducción al análisis cuali vs. cuali (bivariado)

Esta sección es opcional. La idea es conectar lo univariado con el primer bivariado: cómo cambia la lectura cuando cruzamos dos variables categóricas.

Usaremos como ejemplo:

  • tam_loc (tamaño de localidad)
  • clase_hog (tipo/clase de hogar)

Si tu tabla no tiene clase_hog, sustituye por otra variable categórica (por ejemplo estrato u otra disponible).

12.1 1) geom_bar() (cuenta automáticamente)

Barras apiladas (conteos): el alto de la barra depende del número de casos en tam_loc.

concentrado |>
  ggplot() +
  aes(x = as.factor(tam_loc), fill = as.factor(clase_hog)) +
  geom_bar(position = "stack") +
  labs(title = "Cuali × Cuali (conteos): barras apiladas",
       x = "tam_loc", y = "Conteo (muestra)", fill = "clase_hog") +
  ggthemes::theme_few()

Barras apiladas (proporciones): cada barra suma 100% y muestra composición.

concentrado |>
  ggplot() +
  aes(x = as.factor(tam_loc), fill = as.factor(clase_hog)) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(title = "Cuali × Cuali (porcentajes): composición dentro de tam_loc",
       x = "tam_loc", y = "Porcentaje", fill = "clase_hog") +
  ggthemes::theme_few()

Barras lado a lado (dodge): útil con pocas categorías.

concentrado |>
  ggplot() +
  aes(x = as.factor(clase_hog), fill = as.factor(tam_loc)) +
  geom_bar(position = "dodge") +
  coord_flip() +
  labs(title = "Cuali × Cuali (conteos): barras lado a lado",
       x = "clase_hog", y = "Conteo (muestra)", fill = "tam_loc") +
  ggthemes::theme_clean()

position = "dodge2" suele mejorar el espaciado cuando hay categorías desbalanceadas.

concentrado |>
  ggplot() +
  aes(x = as.factor(clase_hog), fill = as.factor(tam_loc)) +
  geom_bar(position = "dodge2") +
  coord_flip() +
  labs(title = "Cuali × Cuali (conteos): dodge2",
       x = "clase_hog", y = "Conteo (muestra)", fill = "tam_loc") +
  ggthemes::theme_clean()

12.2 2) geom_col() (tú calculas conteos o porcentajes)

La ventaja de geom_col() es que controlas el conteo o el porcentaje.

12.2.1 2.1 Tabla de conteos

tab_hog_tam <- concentrado |>
  count(as.factor(clase_hog), as.factor(tam_loc), name = "n") |>
  janitor::clean_names()

tab_hog_tam |> head()

12.2.2 2.2 Conteos apilados con geom_col()

tab_hog_tam |>
  ggplot() +
  aes(x = as_factor_clase_hog, y = n, fill = as_factor_tam_loc) +
  geom_col(position = "stack") +
  coord_flip() +
  labs(title = "Cuali × Cuali (conteos) con geom_col()",
       x = "clase_hog", y = "Conteo", fill = "tam_loc") +
  viridis::scale_fill_viridis_d(begin = 0.2, end = 0.8) +
  ggthemes::theme_few()

12.2.3 2.3 Porcentajes dentro de clase_hog (equivalente a position = "fill")

Aquí calculamos el porcentaje dentro de cada clase_hog.

tab_hog_tam_pct <- tab_hog_tam |>
  group_by(as_factor_clase_hog) |>
  mutate(p = n / sum(n)) |>
  ungroup()

tab_hog_tam_pct |> head()
tab_hog_tam_pct |>
  ggplot() +
  aes(x = as_factor_clase_hog, y = p, fill = as_factor_tam_loc) +
  geom_col() +
  coord_flip() +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(title = "Cuali × Cuali (porcentajes): composición dentro de clase_hog",
       x = "clase_hog", y = "Porcentaje", fill = "tam_loc") +
  scale_fill_brewer(palette = "Set2") +
  ggthemes::theme_clean()

12.2.4 2.4 Etiquetar barras (porcentajes)

tab_hog_tam_pct |>
  ggplot() +
  aes(x = as_factor_clase_hog, y = p, fill = as_factor_tam_loc) +
  geom_col() +
  geom_text(
    aes(label = scales::percent(p, accuracy = 1)),
    position = position_stack(vjust = 0.5),
    size = 3
  ) +
  coord_flip() +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(title = "Cuali × Cuali (porcentajes) con etiquetas",
       x = "clase_hog", y = "Porcentaje", fill = "tam_loc") +
  viridis::scale_fill_viridis_d(option = "plasma", begin = 0.2, end = 0.85) +
  ggthemes::theme_few()

Tip: si se enciman etiquetas, muestra solo las celdas grandes (por ejemplo p >= 0.05).

> `position = "dodge2"` suele mejorar el espaciado cuando hay categorías desbalanceadas.

```{r}

concentrado |>
  ggplot() +

       x = "clase_hog", y = "Conteo (muestra)", fill = "tam_loc") +

```

### 2) `geom_col()` (tú calculas conteos o porcentajes)

La ventaja de `geom_col()` es que **controlas** el conteo o el porcentaje.

#### 2.1 Tabla de conteos

```{r}
#| eval: false
tab_hog_tam <- concentrado |>
  count(as.factor(clase_hog), as.factor(tam_loc), name = "n") |>
  janitor::clean_names()

tab_hog_tam |> head()
```

#### 2.2 Conteos apilados con `geom_col()`

```{r}
#| eval: false
tab_hog_tam |>
  ggplot() +
  aes(x = as_factor_clase_hog, y = n, fill = as_factor_tam_loc) +
  geom_col(position = "stack") +
  coord_flip() +
  labs(title = "Cuali × Cuali (conteos) con geom_col()",
       x = "clase_hog", y = "Conteo", fill = "tam_loc") +
  viridis::scale_fill_viridis_d(begin = 0.2, end = 0.8) +

```

#### 2.3 Porcentajes dentro de `clase_hog` (equivalente a `position = "fill"`)

Aquí calculamos el porcentaje *dentro de cada* `clase_hog`.

```{r}
#| eval: false
tab_hog_tam_pct <- tab_hog_tam |>
  group_by(as_factor_clase_hog) |>
  mutate(p = n / sum(n)) |>
  ungroup()

tab_hog_tam_pct |> head()
```

```{r}
#| eval: false
tab_hog_tam_pct |>
  ggplot() +
  aes(x = as_factor_clase_hog, y = p, fill = as_factor_tam_loc) +
  geom_col() +
  coord_flip() +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(title = "Cuali × Cuali (porcentajes): composición dentro de clase_hog",
       x = "clase_hog", y = "Porcentaje", fill = "tam_loc") +

  ggthemes::theme_clean()
```

#### 2.4 Etiquetar barras (porcentajes)

```{r}
#| eval: false
tab_hog_tam_pct |>
  ggplot() +
  aes(x = as_factor_clase_hog, y = p, fill = as_factor_tam_loc) +
  geom_col() +
  geom_text(
    aes(label = scales::percent(p, accuracy = 1)),
```
