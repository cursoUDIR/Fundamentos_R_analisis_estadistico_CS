5 1. ¿Qué hace el factor de expansión y qué cambia cuando incorporamos el diseño?

  • El factor de expansión permite pasar de la muestra a estimaciones representativas (poblacionales).
  • El diseño muestral (estratos + UPM) determina cómo se calcula la varianza (errores estándar, IC, CV).
  • Tabulados con count(wt = factor) o tally(wt = factor) usan peso, pero no incorporan automáticamente varianza del diseño.
  • Con {srvyr} sí podemos estimar con varianza (por ejemplo vartype = "se" o "ci").

11 7. Coeficiente de variación (CV): concepto e importancia

11.1 7.1 ¿Qué es el CV?

Para una estimación () (por ejemplo, una media o proporción), el coeficiente de variación se define como:

[ CV() = ]

A veces se reporta en porcentaje:

[ CV% = 100 ]

11.2 7.2 ¿Por qué es importante?

  • Resume precisión relativa: no solo “qué tan grande es el error”, sino qué tan grande es respecto a la estimación.
  • Permite evaluar confiabilidad de resultados: estimaciones con CV alto suelen ser inestables (por ejemplo, subpoblaciones pequeñas).
  • En muchos reportes institucionales se usa para decidir si una cifra es “publicable” o debe marcarse como baja precisión.
ImportanteRegla práctica (orientativa)

No hay un umbral universal, pero en práctica aplicada se usa algo como:

  • CV < 15%: buena precisión
  • 15% ≤ CV < 30%: precisión moderada (cuidado en interpretación)
  • CV ≥ 30%: baja precisión (evitar conclusiones fuertes)

Estos umbrales dependen del estándar del proyecto/institución.

11.3 7.3 Calcular CV con resultados de {srvyr}

Opción A: pedir SE y calcular CV manualmente

cv_tab <- diseno |>
  group_by(tam_loc) |>
  summarise(
    media_ing = survey_mean(ing_cor, na.rm = TRUE, vartype = "se")
  ) |>
  mutate(
    cv = media_ing_se / media_ing,
    cv_pct = 100 * cv
  )

cv_tab

Opción B: calcular CV para una proporción

cv_prop <- diseno2 |>
  group_by(tam_loc) |>
  summarise(
    prop_urbano = survey_mean(es_urbano, na.rm = TRUE, vartype = "se")
  ) |>
  mutate(
    cv = prop_urbano_se / prop_urbano,
    cv_pct = 100 * cv
  )

## 7. Coeficiente de variación (CV): concepto e importancia

### 7.1 ¿Qué es el CV?

Para una estimación \(\hat{\theta}\) (por ejemplo, una media o proporción), el **coeficiente de variación** se define como:

\[
CV(\hat{\theta}) = \frac{SE(\hat{\theta})}{\hat{\theta}}
\]

A veces se reporta en porcentaje:

\[
CV\% = 100 \times \frac{SE(\hat{\theta})}{\hat{\theta}}
\]

### 7.2 ¿Por qué es importante?

-   Resume **precisión relativa**: no solo “qué tan grande es el error”, sino qué tan grande es **respecto a la estimación**.
-   Permite evaluar **confiabilidad** de resultados: estimaciones con CV alto suelen ser inestables (por ejemplo, subpoblaciones pequeñas).
-   En muchos reportes institucionales se usa para decidir si una cifra es “publicable” o debe marcarse como **baja precisión**.

::: callout-important
## Regla práctica (orientativa)
No hay un umbral universal, pero en práctica aplicada se usa algo como:

- CV < 15%: buena precisión  
- 15% ≤ CV < 30%: precisión moderada (cuidado en interpretación)  
- CV ≥ 30%: baja precisión (evitar conclusiones fuertes)

Estos umbrales dependen del estándar del proyecto/institución.
:::
