1 Objetivos de la sesión

Al finalizar esta sesión podrán:

  • Instalar un paquete desde GitHub cuando no está en CRAN (con {remotes} o {pak}).
  • Construir indicadores por entidad y municipio a partir de tablas (ENIGH 2024 como ejemplo).
  • Preparar llaves tipo region en el formato esperado por {mxmaps}.
  • Elaborar mapas coropléticos con mxstate_choropleth() y mxmunicipio_choropleth().
  • Tomar decisiones básicas de clasificación (num_colors) y escribir una lectura crítica del mapa.
  • Exportar mapas como imagen con ggsave().

2 Contenidos

  • Instalación de paquetes fuera de CRAN: remotes::install_github() o pak::pkg_install().
  • Indicadores por región (estado/municipio): group_by() + summarise().
  • Mapas con {mxmaps}:
    • mxstate_choropleth() (estatal)
    • mxmunicipio_choropleth() (municipal)
  • Preparación de llaves con mxmaps::str_mxstate() y mxmaps::str_mxmunicipio().
  • Lectura crítica: clasificación, comparabilidad, tamaño muestral y límites de interpretación.

Paquetes: {mxmaps} {dplyr} {janitor} {stringr} {ggplot2} {arrow} {readr}
Funciones clave: remotes::install_github() · pak::pkg_install() · mxstate_choropleth() · str_mxstate() · group_by() · summarise() · ggsave()

3 Guía de instalación (paquetes que no están en CRAN)

3.1 Opción A: instalar con {remotes}

install.packages("remotes")
remotes::install_github("diegovalle/mxmaps")

3.2 Opción B: instalar con {pak}

install.packages("pak")
pak::pkg_install("diegovalle/mxmaps")

3.3 Diferencia rápida: {remotes} vs {pak}

  • {remotes} es ligero y suele ser la opción “mínima” para instalar desde GitHub.
  • {pak} también instala desde GitHub, pero además intenta resolver dependencias y usa un proceso de instalación más moderno.
NotaNota sobre errores 401 (credenciales)

Si aparece un error tipo HTTP 401 (Unauthorized) al instalar desde GitHub, suele haber un token inválido configurado en esa computadora. En ese caso, conviene usar {remotes} y/o revisar Sys.getenv("GITHUB_PAT") dentro de R.

concentrado <- arrow::read_parquet(here::here("data", "raw", "concentradohogar.parquet")) |>

# Opción 2: CSV
concentrado <- readr::read_csv(here::here("data", "raw", "concentradohogar.csv"),
                               show_col_types = FALSE) |>

6 1) Indicador estatal (region, value)

mxmaps espera un data.frame con dos columnas:

  • region: clave estatal INEGI como “01”, “02”, …, “32”
  • value: indicador numérico a mapear

Ejemplo: media de ing_cor por entidad (a partir de ubica_geo).

indic_est <- concentrado |>
  mutate(region = stringr::str_sub(ubica_geo, 1, 2)) |>
  group_by(region) |>
  summarise(
    value = mean(ing_cor, na.rm = TRUE),
    n = n(),
    .groups = "drop"
  ) |>
  mutate(region = mxmaps::str_mxstate(region))

7 2) Mapa estatal con {mxmaps}

g_map_5 <- mxmaps::mxstate_choropleth(indic_est, num_colors = 5)
g_map_9 <- mxmaps::mxstate_choropleth(indic_est, num_colors = 9)

g_map_5
g_map_9

8 3) Exportación con ggsave()

mxmaps::mxstate_choropleth() devuelve un objeto tipo ggplot, así que se puede exportar con ggsave().

ggplot2::ggsave("fig_p14_mapa_estatal_5colores.png", plot = g_map_5, width = 7, height = 5, dpi = 300)
ggplot2::ggsave("fig_p14_mapa_estatal_9colores.png", plot = g_map_9, width = 7, height = 5, dpi = 300)

9 4) Indicador municipal (opcional)

Para municipio, region debe ser entidad+municipio (5 dígitos): “EEMMM”.

indic_mun <- concentrado |>
  mutate(region = stringr::str_sub(ubica_geo, 1, 5)) |>
  group_by(region) |>
  summarise(
    value = mean(ing_cor, na.rm = TRUE),
    n = n(),
    .groups = "drop"
  ) |>
  mutate(region = mxmaps::str_mxmunicipio(region))
g_mun <- mxmaps::mxmunicipio_choropleth(indic_mun, num_colors = 7)
g_mun
ggplot2::ggsave("fig_p14_mapa_municipal.png", plot = g_mun, width = 8, height = 6, dpi = 300)
