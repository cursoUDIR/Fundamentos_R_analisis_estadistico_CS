3 Guía de instalación (paquetes que no están en CRAN)

A veces un paquete no está disponible en CRAN. En ese caso, se instala desde GitHub.

3.1 1) Instalar {remotes} (una vez)

install.packages("remotes")

3.2 2) Instalar {mxmaps} desde GitHub

remotes::install_github("diegovalle/mxmaps")

3.3 ¿Cuál es la diferencia entre {remotes} y {devtools}?

  • {remotes} es un paquete ligero cuyo objetivo principal es instalar paquetes desde GitHub (u otras fuentes) sin traer dependencias extra.
  • {devtools} es un paquete más grande, pensado para desarrollo de paquetes (documentación, pruebas, chequeos, etc.).
    • {devtools} incluye a {remotes} como dependencia y, por eso, también puede hacer devtools::install_github().
  • Para este curso: preferimos {remotes} porque es más simple y rápido de instalar.

6 1) Indicador a nivel estatal (entidad)

En ENIGH, ubica_geo suele contener entidad y municipio en el mismo código (entidad=2 dígitos, municipio=3 dígitos).

indic_est <- concentrado |>
  mutate(region = stringr::str_sub(ubica_geo, 1, 2)) |>
  group_by(region) |>
  summarise(
    value = mean(ing_cor, na.rm = TRUE),
    n = n(),
    .groups = "drop"
  ) |>
  mutate(region = mxmaps::str_mxstate(region))
  • region: clave estatal en formato esperado por {mxmaps}
  • value: indicador a mapear (aquí, media de ing_cor)

7 2) Mapa estatal con {mxmaps}

mxmaps::mxstate_choropleth(
  indic_est,
  num_colors = 7
)
NotaNota

num_colors controla el número de clases de color (binned). Más colores no siempre es mejor: puede dificultar la lectura.

8 3) Indicador municipal (opcional)

Para municipio, construimos una clave de 5 dígitos: entidad (2) + municipio (3).

indic_mun <- concentrado |>
  mutate(
    region = stringr::str_sub(ubica_geo, 1, 5)  # "EEMMM"
  ) |>
  group_by(region) |>
  summarise(
    value = mean(ing_cor, na.rm = TRUE),
    n = n(),
    .groups = "drop"
  ) |>
  mutate(region = mxmaps::str_mxmunicipio(region))

9 4) Mapa municipal con {mxmaps} (opcional)

mxmaps::mxmunicipio_choropleth(
  indic_mun,
  num_colors = 7
)
ImportanteRecomendación práctica

El mapa municipal puede verse muy saturado o con muchos vacíos. Si quieren, filtren a una entidad y mapeen solo sus municipios.

10 5) Exportación (una opción simple)

En {mxmaps}, los mapas (choropleths) se generan como objetos tipo ggplot. Esto permite guardarlos directamente con ggsave() sin abrir/cerrar un dispositivo gráfico manualmente.

# Crear el mapa como objeto (ggplot)
g_map_est <- mxmaps::mxstate_choropleth(
  indic_est,
  num_colors = 7
)

# Guardarlo como imagen
ggplot2::ggsave(
  filename = "fig_p14_mapa_estatal.png",
  plot = g_map_est,
  width = 7,
  height = 5,
  dpi = 300
)
