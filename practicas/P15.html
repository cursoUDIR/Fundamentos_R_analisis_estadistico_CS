1 Objetivos de la sesión

5 1) ¿Cómo se arma un documento Quarto? (idea mínima)

Un archivo .qmd tiene tres partes:

  1. Encabezado YAML (título, autoría, formato).
  2. Texto en Markdown (títulos, listas, párrafos).
  3. Chunks de código (resultados reproducibles).

Ejemplo mínimo (plantilla):

# ---
# title: "Mi reporte"
# author: ["Nombre 1", "Nombre 2"]
# format: html
# ---
#
# ## Sección
#
# Texto...
#
# ```{r}
# # Código...
# ```

Opciones generales (se suelen definir una vez):

knitr::opts_chunk$set(
  echo = TRUE,
  warning = FALSE,
  message = FALSE
)

6 2) Tabla + 2 figuras (mínimo del cierre)

6.1 2.1 Tabla descriptiva (ejemplo)

tabla <- concentrado |>
  summarise(
    n = n(),
    media_ing = mean(ing_cor, na.rm = TRUE),
    mediana_ing = median(ing_cor, na.rm = TRUE),
    sd_ing = sd(ing_cor, na.rm = TRUE)
  )

gt::gt(tabla)

6.2 2.2 Dos figuras (ejemplo)

g_hist <- ggplot(concentrado, aes(x = ing_cor)) +
  geom_histogram(binwidth = 5000) +
  labs(title = "Histograma de ing_cor", x = "ing_cor", y = "Frecuencia") +
  theme_minimal()

g_box <- ggplot(concentrado |> filter(ing_cor > 0), aes(y = ing_cor)) +
  geom_boxplot() +
  scale_y_log10(labels = scales::label_number(big.mark = ",")) +
  labs(title = "Boxplot (log10) de ing_cor", y = "ing_cor (log10)") +
  theme_minimal()

g_hist
g_box

8 4) ¿Cómo hacer un mini-sitio web con Quarto? (muy breve)

Un sitio web de Quarto es un proyecto con un archivo _quarto.yml y páginas .qmd.

8.1 4.1 Estructura mínima

  • _quarto.yml
  • index.qmd
  • about.qmd (opcional)

Ejemplo de _quarto.yml (mínimo):

# project:
#   type: website
# website:
#   title: "Sitio del Módulo 3"
#   navbar:
#     left:
#       - href: index.qmd
#         text: Inicio
#       - href: about.qmd
#         text: Acerca de
# format:
#   html:
#     theme: cosmo
#     toc: true

Render del sitio (genera carpeta _site/):

# En la terminal o consola del proyecto:
# quarto render

9 5) ¿Cómo hacer una presentación PPTX con Quarto? (muy breve)

Una presentación PPTX se genera con format: pptx en el YAML.

Plantilla mínima para slides_p15.qmd:

# ---
# title: "Resultados del Módulo 3"
# author: ["Nombre 1", "Nombre 2"]
# format: pptx
# ---
#
# ## Figura 1
#
# ```{r}
# # Gráfica...
# ```
#
# ## Figura 2
#
# ```{r}
# # Gráfica...
# ```

Render (produce un archivo .pptx):

quarto::quarto_render("slides_p15.qmd")
