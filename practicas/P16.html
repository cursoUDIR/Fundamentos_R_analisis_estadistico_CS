5 2) Normal vs t (cuantiles)

qnorm(0.975)      # z crítico 95%
qt(0.975, df = 9) # t crítico 95% con n=10 (df=9)
NotaRegla práctica

Para IC de una media con () desconocida (casi siempre): usa t. Con n grande, t y z se acercan; con n pequeño, t produce IC más amplios.

6 3) IC para una media (una muestra) — ing_cor

df_q <- concentrado |>
  filter(!is.na(ing_cor))

6.1 3.1 Enfoque base: t.test()

res_base_media <- t.test(df_q$ing_cor, conf.level = 0.95)
res_base_media$estimate
res_base_media$conf.int
res_base_media$parameter

6.2 3.2 Enfoque tidy: {infer} con infer::t_test()

res_infer_media <- df_q |>
  infer::t_test(response = ing_cor, mu = 0, conf_level = 0.95)

res_infer_media
Nota¿Por qué infer::t_test() y no get_confidence_interval()?

En versiones recientes de {infer}, get_confidence_interval() está pensado para distribuciones generadas por remuestreo (percentile / se / bias-corrected). Para IC “paramétricos” (t/normal), la vía directa y estable es infer::t_test() / infer::prop_test().

7 4) IC para una proporción (una muestra) — recibe_remesas

Definimos una binaria: recibe_remesas = 1 si remesas > 0, 0 si no.
Para {infer}, haremos la variable como factor con niveles "0" y "1" para que success sea texto.

df_b <- concentrado |>
  mutate(
    recibe_remesas = if_else(!is.na(remesas) & remesas > 0, 1, 0),
    recibe_remesas = factor(recibe_remesas, levels = c(0, 1))
  ) |>
  filter(!is.na(recibe_remesas))

x <- sum(df_b$recibe_remesas == "1")
n <- nrow(df_b)
x; n

7.1 4.1 Enfoque base: prop.test()

res_base_prop <- prop.test(x = x, n = n, conf.level = 0.95)
res_base_prop$estimate
res_base_prop$conf.int

7.2 4.2 Enfoque tidy: {infer} con infer::prop_test()

res_infer_prop <- df_b |>
  
  infer::prop_test(response = recibe_remesas, success = "1", conf_level = 0.95)

res_infer_prop
ImportanteProporciones: cuidado con n pequeño o () extremo

El IC Wald (aprox. normal simple) puede ser inestable si (n) es pequeño o () está cerca de 0 o 1. prop.test() suele comportarse mejor como primer acercamiento.

### 4.1 Enfoque base: `prop.test()`
