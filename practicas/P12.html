Práctica 12 (Sesión 12): Gráficos con dos variables (bivariado)

Cuali–cuali, cuali–cuanti y cuanti–cuanti + escalas de color y temas

Autores/as

Ana Escoto

Mónica Lara

Fecha de publicación

10 de junio de 2026

1 Objetivos de la sesión

Al finalizar esta sesión podrán:

  • Construir visualizaciones bivariadas para (i) cuali–cuali, (ii) cuali–cuanti y (iii) cuanti–cuanti.
  • Elegir entre conteos y proporciones en barras apiladas (position = "fill").
  • Usar codificación estética (color/fill/shape) de manera legible y consistente.
  • Aplicar escalas de color apropiadas (viridis, RColorBrewer) y temas (ggthemes) para mejorar comunicación.
  • Exportar figuras listas para reporte con ggsave().

2 Contenidos

  • Cuali–cuali: barras apiladas (conteos y proporciones) y lectura crítica.
  • Cuali–cuanti: boxplot por grupo y comparación descriptiva.
  • Cuanti–cuanti: dispersión y tendencia (geom_smooth()).
  • Escalas de color: scale_fill_viridis_d(), scale_color_viridis_d(), scale_fill_brewer().
  • Temas y estilo: theme_minimal() y temas de {ggthemes}.

Paquetes: {ggplot2} {dplyr} {forcats} {scales} {viridis} {RColorBrewer} {ggthemes} {janitor}
Funciones clave: geom_bar() · geom_col() · geom_boxplot() · geom_point() · geom_smooth() · scale_fill_viridis_d() · scale_fill_brewer() · theme_*() · facet_wrap() · ggsave()

5 1) Cuali–cuali: barras apiladas (conteos y proporciones)

Usaremos como ejemplo tam_loc y est_socio (ajusta si tu tabla usa otros nombres).

5.1 1.1 Conteos apilados

g_cc_conteo <- ggplot(concentrado, aes(x = as.factor(tam_loc), fill = as.factor(est_socio))) +
  geom_bar() +
  labs(
    title = "Cuali–cuali (conteos): tam_loc × est_socio",
    x = "tam_loc",
    y = "Conteo (muestra)",
    fill = "est_socio"
  ) +
  ggthemes::theme_few()

g_cc_conteo

5.2 1.2 Proporciones apiladas (porcentajes)

g_cc_prop <- ggplot(concentrado, aes(x = as.factor(tam_loc), fill = as.factor(est_socio))) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(
    title = "Cuali–cuali (proporciones): tam_loc × est_socio",
    x = "tam_loc",
    y = "Porcentaje",
    fill = "est_socio"
  ) +
  ggthemes::theme_few()

g_cc_prop

5.3 1.3 Colores: viridis vs Brewer (fill discreto)

g_cc_viridis <- g_cc_prop + scale_fill_viridis_d()

g_cc_brewer <- g_cc_prop + scale_fill_brewer(palette = "Set2")

g_cc_viridis
g_cc_brewer
Nota¿Conteos o proporciones?
  • Conteos: útiles para ver tamaño absoluto de grupos en la muestra.
  • Proporciones: útiles para comparar composición (estructura) entre categorías.

6 2) Cuali–cuanti: boxplot por grupo

Ejemplo: ing_cor por tam_loc (ajusta la variable cuantitativa si aplica).

g_cq_box <- ggplot(concentrado, aes(x = as.factor(tam_loc), y = ing_cor, fill = as.factor(tam_loc))) +
  geom_boxplot(show.legend = FALSE) +
  labs(
    title = "Cuali–cuanti: boxplot de ing_cor por tam_loc",
    x = "tam_loc",
    y = "ing_cor"
  ) +
  scale_fill_viridis_d() +
  ggthemes::theme_clean()

g_cq_box

Opcional: escala log (si hay cola larga y valores > 0):

g_cq_box_log <- ggplot(concentrado |> filter(ing_cor > 0), aes(x = as.factor(tam_loc), y = ing_cor, fill = as.factor(tam_loc))) +
  geom_boxplot(show.legend = FALSE) +
  scale_y_log10(labels = scales::label_number()) +
  scale_fill_viridis_d() +
  labs(
    title = "Cuali–cuanti: boxplot de ing_cor por tam_loc (log10)",
    x = "tam_loc",
    y = "ing_cor (log10)"
  ) +
  ggthemes::theme_clean()

g_cq_box_log

7 3) Cuanti–cuanti: dispersión y tendencia

Ejemplo: ing_cor vs gasto_mon (ajusta si tu tabla usa otros nombres).

g_qq <- ggplot(concentrado, aes(x = gasto_mon, y = ing_cor)) +
  geom_point(alpha = 0.4) +
  geom_smooth(method = "lm", se = TRUE) +
  scale_x_continuous(labels = scales::label_number(big.mark = ",")) +
  scale_y_continuous(labels = scales::label_number(big.mark = ",")) +
  labs(
    title = "Cuanti–cuanti: dispersión ing_cor vs gasto_mon",
    x = "gasto_mon",
    y = "ing_cor"
  ) +
  ggthemes::theme_few()

g_qq

7.1 3.1 Codificación por grupo (color) + viridis

g_qq_color <- ggplot(concentrado, aes(x = gasto_mon, y = ing_cor, color = as.factor(tam_loc))) +
  geom_point(alpha = 0.4) +
  geom_smooth(method = "lm", se = FALSE) +
  scale_color_viridis_d() +
  labs(
    title = "Cuanti–cuanti con grupo: ing_cor vs gasto_mon (color = tam_loc)",
    x = "gasto_mon",
    y = "ing_cor",
    color = "tam_loc"
  ) +
  ggthemes::theme_clean()

g_qq_color

8 4) Facetas (opcional) para comparación

g_qq_facetas <- ggplot(concentrado, aes(x = gasto_mon, y = ing_cor)) +
  geom_point(alpha = 0.3) +
  geom_smooth(method = "lm", se = FALSE) +
  facet_wrap(~ tam_loc) +
  scale_x_continuous(labels = scales::label_number(big.mark = ",")) +
  scale_y_continuous(labels = scales::label_number(big.mark = ",")) +
  labs(
    title = "Cuanti–cuanti por facetas: ing_cor vs gasto_mon (por tam_loc)",
    x = "gasto_mon",
    y = "ing_cor"
  ) +
  theme_minimal()

g_qq_facetas
